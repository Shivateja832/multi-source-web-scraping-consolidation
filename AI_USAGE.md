# AI Usage Disclosure

GitHub Copilot in VS Code was used as an assistant during development, maintenance, and verification of this project. The project author remains responsible for reviewing, understanding, and submitting the application.

## Areas where AI assistance was used

- **Scraping implementation:** helped implement and refine the Books to Scrape and Quotes to Scrape collectors, pagination, parsing, and source URL handling.
- **Data processing:** helped implement or update record normalization, validation, numeric and URL handling, and duplicate detection.
- **Reliability and configuration:** helped with environment-based settings, request timeouts, retries and backoff, rate limiting, logging, health checks, and pipeline status reporting.
- **Deployment and operations:** helped configure Docker and Docker Compose, CI checks, scheduled GitHub Actions runs, output validation, failure alerts, and GitHub Pages publishing.
- **Tests and debugging:** helped create and update tests, diagnose reported errors, and add regression coverage for identified issues.
- **Documentation and maintenance:** helped update project documentation, this disclosure, and remove a redundant project copy and generated caches.
- **Verification:** helped run and interpret tests, lint checks, runtime health checks, scraper runs, container builds, and GitHub Actions deployment results.

AI assistance does not replace the project author's responsibility for the code or guarantee that the application is free of defects in every environment. The checks performed and their results are reported separately in the project documentation and CI history.
